# Scripts

Repo guarda-chuva para scripts utilitarios e automacoes pontuais.

## Projetos

- `course-content-migration/`: automacao de migracao de conteudo, aulas e assets de cursos.
- `student-migration/`: preparacao e validacao de migracao de alunos a partir de CSV.

Cada pasta deve manter seu proprio `package.json`, README, configuracao e testes para que os scripts aparecam separados no GitHub sem misturar dependencias ou comandos.
